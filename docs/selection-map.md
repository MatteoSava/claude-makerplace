# Selection Map

This package keeps the selected skill set small and grouped by operational domain.

## Agentic Research

- `skill-autoresearch-loop`: keeps skills self-improving after real feedback.
- `agentic-experiment-loop`: supports bounded agent experiments.
- `benchmark-run-operations`: handles reproducible benchmark runs.
- `experiment-registry`: preserves run metadata and promotion state.
- `score-model-probe`: investigates opaque score behavior.

## Cloud Delivery

- `azure-container-app-deploy`: deployment and runtime diagnosis.
- `template-pipeline-authoring`: pipeline generation from template catalogs.
- `azure-devops-pr-workflow`: Azure DevOps PR creation and update flow.
- `work-item-linking`: work item lookup and PR linking.
- `authentication-troubleshooting`: browser, API, and cloud auth diagnosis.
- `internal-wiki-query`: citation-preserving documentation lookup.
- `trmnl-terminus-ops`: e-ink device operations workflow.

## Product Engineering

- `react-typescript-standards`: React and TypeScript implementation guidance.
- `sse-chat-streaming`: explicit streaming protocol guidance.
- `playwright-ui-validation`: browser-level UI validation.
- `telegram-miniapp-feature`: Telegram Mini App feature workflow.
- `ton-wallet-integration`: wallet and payment integration workflow.
- `intent-system-extension`: deterministic intent-system extension workflow.

## Python Quality

- `python-quality-gate`: uv-only Python quality gate.
- `python-tdd`: strict Red-Green-Refactor workflow for Python changes.

## Repository Documentation

- `repo-docs-wiki`: source-grounded docs/ wiki creation, ingest, query, lint, and repair workflow.

## Agent Harness Control

- `repo-sentinel`: deterministic repository guardrails for Claude Code and Codex hooks.
